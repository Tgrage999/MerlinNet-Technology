# MerlinNet Technology

MerlinNet Technology is a static website with a local, rule-based virtual assistant named Merlin. The chatbot replies to common questions about the company's services, project enquiries, pricing, and contact details. It does not connect to Google Gemini or another AI service, and chat messages are not sent to a server.

## Open the website

Open `index.html` in a web browser. The website has no server or package installation requirements.

The [`merlinnet logo.png`](./merlinnet%20logo.png) image is used for the header, footer, and circular chatbot button. Replace that file to update the logo across the site. Use the circular logo button to open Merlin. For a custom project enquiry, the contact form prepares a message in the visitor's email application; it does not send the email automatically.

The page also includes a softly pulsing blue-and-gold background glow and colored “MERLINNET TECHNOLOGY” letter trails that fall at different speeds. These effects do not block page controls and are hidden when a visitor's device requests reduced motion.
