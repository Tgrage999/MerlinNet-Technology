# MerlinNet Technology

MerlinNet Technology is a static website with a local, rule-based virtual assistant named Emrys. The chatbot replies to common questions about the company's services, project enquiries, pricing, and contact details. It does not connect to Google Gemini or another AI service, and chat messages are not sent to a server.

## Open the website

Open `index.html` in a web browser. The website has no server or package installation requirements.

The [`merlinnet logo.png`](./merlinnet%20logo.png) image is used for the header, footer, and circular chatbot button. Replace that file to update the logo across the site. Use the circular logo button to open Emrys. For a custom project enquiry, the contact form prepares a message in the visitor's email application; it does not send the email automatically.

The page also includes a softly pulsing blue-and-gold background glow and colored “MERLINNET TECHNOLOGY” letter trails that fall at different speeds. These effects do not block page controls and are hidden when a visitor's device requests reduced motion.

## Content and search visibility

The single-page site presents services first, followed by the founder/team introduction, public questions and answers, and contact options. Main content is included directly in HTML. Keep service availability and pricing answers consistent with the chatbot in `script.js`. The enquiry form prepares an email; it does not submit messages to a server.

The canonical URL and social metadata use `https://merlinnet-technology.netlify.app/`. Update both if the primary domain changes. Logo images use Netlify Image CDN; view the site through Netlify to load the optimized images.

Founder names, credentials, exact service areas, project examples, and response-time promises have not been supplied. Add verified details when available rather than inventing them.
